# crewboard

`crewboard` is the command-line interface for managing Crewboard plans, runs, and review workflows. `orch` is an equivalent command name.

```sh
npm install -g crewboard
crewboard --help
# or: orch --help
```

Requires Node.js 24 or newer and Git. Run commands from a Git repository; use `crewboard init` to create its local orchestration files.

See the [Crewboard repository](https://github.com/Kjaly/crewboard#readme), [getting started](https://github.com/Kjaly/crewboard/blob/main/docs/en/getting-started.md), and the [CLI reference](https://github.com/Kjaly/crewboard/blob/main/docs/en/cli.md).
