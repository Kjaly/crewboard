# crewboard

Watch and steer coding agents from your lead chat. Claude Code leads over MCP; Codex, Claude and DeepSeek do the work; a local web screen shows what is happening now, the conversation behind it and what it cost.

```sh
crewboard serve
claude mcp add --transport http crewboard http://127.0.0.1:4700/mcp
```

Documentation: https://github.com/Kjaly/crewboard#readme
