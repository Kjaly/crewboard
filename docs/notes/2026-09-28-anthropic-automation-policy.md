# Claude в Crewboard: правила доступа и API-only политика

Дата проверки источников: **2026-09-28**. Это запись проверенных сведений и решения продукта, а не заключение о причине блокировки конкретного аккаунта.

## Инцидент и подтверждённые факты

Пользователь сообщил о предполагаемой блокировке Claude после автоматизированного использования подписки через CLI. Причина не подтверждена Anthropic; Crewboard не устанавливает её по последовательности событий.

- [Consumer Terms](https://www.anthropic.com/legal/consumer-terms), раздел 3: автоматизированный доступ ограничен, но предусмотрены исключения для API-ключа и явно разрешённых случаев. Открытая версия датирована 2025-10-08 и относится к потребителям EEA/Швейцарии; её нельзя выдавать за универсальный региональный текст.
- [Legal and compliance](https://code.claude.com/docs/en/legal-and-compliance) разделяет обычное использование штатного Claude Code и интеграции продуктов/сервисов. Для интеграций рекомендованы коммерческий API или поддерживаемые облачные каналы. Ограничения посредничества в Claude.ai авторизации не равны запрету любого запуска официального CLI.
- [Справка Agent SDK](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan), обновление 15 июня: объявленный переход биллинга приостановлен; SDK, неинтерактивный CLI и соответствующие приложения пока используют подписочные лимиты. Сохранённый ниже старый план не вступил в силу.
- [Authentication](https://code.claude.com/docs/en/iam): OAuth Console относится к коммерческому API и отличается от OAuth Claude.ai. Само слово OAuth не определяет подписочный канал.
- [Headless / bare mode](https://code.claude.com/docs/en/headless): bare-режим исключает чтение сохранённой OAuth-авторизации и системного keychain. Для прямого API нужен явно переданный ключ. Сумма из CLI JSON является клиентской оценкой и может отличаться от счёта, особенно при продолжении старой беседы.

## Решение Crewboard

**Собственная политика продукта строже возможных разрешённых исключений:** автоматические воркеры Claude допускаются только через поддерживаемый коммерческий API-канал. Подписочный, неизвестный и противоречивый способы блокируются. Согласие принять риск, принудительный запуск и пропуск preflight не должны обходить эту защиту.

Статус реализации: **защита добавлена в ядро** с ревизией политики anthropic-api-only-2026-09-28. Она действует после обновления сборки Crewboard. На текущей машине известные Claude CLI-профили оставлены выключенными до явной настройки API и решения владельца включить нужный профиль.

Первая ограниченная реализация поддерживает штатный Claude Code версии не ниже 2.1.281 с проверенной поддержкой bare-режима, явный ANTHROPIC_API_KEY и прямой Anthropic API. Неизвестные заголовки, дополнительные способы входа, пользовательские маршрутизационные флаги и неподдерживаемые шлюзы блокируются. Коммерческий Console OAuth, облако или шлюз, который адаптер ещё не проверяет, обозначается как неподдерживаемый способ, а не как нарушение условий. Наличие ключа не доказывает его действительность, доступный баланс или успешную авторизацию.

Crewboard не должен сам переводить подписку на платный API, включать ранее отключённый профиль, извлекать пользовательские токены или предлагать обход ограничений аккаунта. Интерактивный Claude Code вне Crewboard и пользовательские настройки входа остаются за пределами этой политики.

## Диагностика, учёт и сохранность

- Пользователь получает конкретную причину отказа и следующий шаг: настроить поддерживаемый API-канал либо выбрать доступного воркера.
- В интерфейс, журнал и сообщения попадают только названия источников и безопасные метаданные. Значения ключей, токены, cookie, идентификаторы аккаунта и файлы авторизации не прикладываются к отчётам.
- Запрет действует и на продолжение/повторный запуск, прямой backend и подготовку черновика; исторические результаты и рабочие копии сохраняются.
- API-счёт, оценка стоимости и квота подписки остаются разными величинами. API-авторизация не превращает клиентскую оценку CLI в подтверждённые деньги.
- При ограничении аккаунта нужны штатная поддержка и апелляция Anthropic. Эта защита устраняет конкретный неподдерживаемый маршрут, но не обещает отсутствие любых ограничений провайдера.
- Правила других провайдеров проверяются отдельно.

## Перепроверка
