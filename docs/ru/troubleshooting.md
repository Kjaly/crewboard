# Если что-то не так

[English](../en/troubleshooting.md) | **Русский**

## Экран пишет «Нет связи с сервером»

Сервер остановился. Запустите его снова командой `crewboard serve`: экран сам переподключится и перечитает данные.

## Порт занят

`crewboard serve --port 4710`. Подключите ведущего к тому же порту — `claude mcp add --transport http crewboard http://127.0.0.1:4710/mcp`, — а ожидание ведущего запускайте с `--port 4710`.

## Claude Code не видит инструменты

Проверьте, что `claude mcp list` показывает `crewboard` и что сервер запущен. После перезапуска сервера Claude Code переподключается при следующем вызове. Если не переподключился, начните чат заново.

## Поручение Claude пишет «Запуск упал: … anthropic_api_key_missing»

Автоматическим запускам Claude нужен `ANTHROPIC_API_KEY` в окружении сервера. Подробнее в руководстве по [исполнителям](workers.md#claude-нужен-ключ-api).

## Поручение Codex падает с «model not supported»

Аккаунту недоступна эта модель. Попросите ведущего указать другую `model` или проверьте, что `codex` работает сам по себе.

## «История» пишет «Полный разговор недоступен»

Crewboard ищет транскрипты в `~/.claude/projects`, в папках репозитория и его подпапок, и показывает чаты, которые вызывали Crewboard для этой цели. Он ничего не находит, если ведущим был не Claude Code, если ведущий работал в папке вне репозитория или если транскрипты удалены. Переменная `CREWBOARD_CLAUDE_PROJECTS` указывает другую папку транскриптов.

## Ведущий показан «не на связи», хотя работает

Ведущий считается на связи, пока он вызывает Crewboard или ждёт через `crewboard wait`. Если ведущий долго думает без того и другого, через 10 минут появляется «ведущий не на связи». Следующий вызов это исправляет.

## Цель «На паузе»

Её ведущий молчит больше суток. Откройте чат в репозитории и попросите подхватить цель — он вызовет `crewboard_adopt_goal`.

## `crewboard wait` завершается с кодом 1

На этом порту не запущен сервер или путь не внутри Git-репозитория. Сообщение скажет, что именно.
