# Затраты

[English](../en/costs.md) | **Русский**

Crewboard записывает, сколько стоил каждый запуск, в момент его окончания и показывает это в «Аналитике» — по провайдерам и по поручениям.

## Три вида чисел, которые не смешиваются

| Колонка | Что это |
| --- | --- |
| Деньги | сколько стоил запуск по словам провайдера |
| По ценам API | оценка: токены запуска по публичным ценам API провайдера |
| Токены: вход / выход | сколько запуск прочитал и написал |

Значение, которое провайдер не сообщает, показывается как «нет данных». Это никогда не ноль: запуск по подписке без цены остаётся «нет данных» в колонке «Деньги», а не $0.

## Откуда берутся числа

- **Codex** сообщает токены. По подписке он денег не сообщает, и Crewboard оценивает цену по ценам API для моделей из своей таблицы цен. Для модели, которой нет в таблице (сейчас это `gpt-6.1-sol` по умолчанию), оценка — «нет данных».
- **Claude** сообщает токены и деньги. Если у запуска своих цифр нет, Crewboard берёт их из транскрипта Claude Code этого запуска.
- **DeepSeek через dsh** сообщает то, что записывает dsh.

У запуска, который упал до старта, затрат нет, и в дорожки и таблицы он не попадает.
