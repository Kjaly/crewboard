# Затраты

[English](../en/costs.md) | **Русский**

Crewboard записывает, сколько стоил каждый запуск, в момент его окончания и показывает это в «Аналитике» — по провайдерам и по поручениям.

## Три вида чисел, которые не смешиваются

| Колонка | Что это |
| --- | --- |
| Деньги | сколько стоил запуск по словам провайдера |
| По ценам API | оценка: токены запуска по публичным ценам API провайдера |
| Токены: вход / выход | сколько запуск прочитал и написал |

Значение, которое провайдер не сообщает, показывается как «нет данных». Это никогда не ноль: запуск по подписке без цены остаётся «нет данных» в колонке «Деньги», а не $0.

## Откуда берутся числа

- **Codex** сообщает токены. По подписке он денег не сообщает, и Crewboard оценивает цену по ценам API для моделей из своей таблицы цен. Модель по умолчанию `gpt-6.1-sol` есть в таблице: её тарифы проверены 2026-11-03; старые записи сохраняют дату тарифов 2026-09-25. Для модели, которой нет в таблице, оценка — «нет данных».
- **Claude** сообщает токены и сумму в долларах. При входе по плану Claude эта сумма — оценка Claude Code по ценам API, а не списание: Crewboard показывает её в колонке «По ценам API», а в колонке «Деньги» пишет «по подписке». При входе по ключу это стоимость запуска. Если у запуска своих цифр нет, Crewboard берёт их из транскрипта Claude Code этого запуска.
- **Любой другой агент** показывает то, что сообщает его адаптер; цена, которую он не сообщает, остаётся «нет данных».
- **DeepSeek через dsh** сообщает то, что записывает dsh.

У запуска, который упал до старта, затрат нет, и в дорожки и таблицы он не попадает.
