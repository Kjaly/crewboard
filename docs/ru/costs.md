# Затраты

[Документация](../README.md) · [English](../en/costs.md) | **Русский**

Воркеры оплачиваются по-разному: одни за токены через API, другие по подписке, третьи по промо. Crewboard записывает то, что на самом деле сообщает источник каждого запуска, и не смешивает эти виды чисел. Оценка не превращается в списание, а отсутствующее число не показывается нулём.

![Журнал запусков: два запуска с воркером, моделью, учтёнными расходами API, оценкой по тарифам API и недоступной стоимостью](../assets/run-ledger.png)

*Два запуска: у одного учтены расходы API, у другого — оценка по тарифам API, а одно из чисел недоступно.*

## Что означает каждое число

| На экране | В `crewboard cost --json` | Что это |
| --- | --- | --- |
| **«Учтённые расходы API»** | `cashUsd` | Деньги, которые источник записал как списанные за запуск: записи учёта dsh для воркеров dsh или сумма, которую сообщил сам воркер с оплатой через API. |
| **«Эквивалент по тарифам API»** с пометкой **«Оценка, не списание»** | `apiEquivalentUsd` | Для воркеров по подписке (Claude Code, Codex): сколько стоили бы токены запуска по тарифам API. **Это не списанные с вас деньги**, а способ сравнить воркеров. |
| **«Изменение квоты подписки»**, **«Квота потрачена»** | `quotaMeasurements`, `quotaDeltaPct` | Какую часть окна подписки израсходовал запуск — по замерам до и после. |
| **«Токены»** — вход, выход, чтение и запись кэша | `tokens` | Число токенов, если источник его сообщает. |
| **«Ожидаются данные расхода»** | `pending: true`, `availability.*: "pending"` | Источник ещё не учёл запуск. В итоги он не входит. |
| **«Неполные данные»** | `availability.*: "partial"` | Измерена только часть запуска. |
| **«Недоступно»** | `availability.*: "unavailable"` | Источник не даёт этого числа. Оно неизвестно, а не равно нулю. |
| **«Не применимо»** | `availability.cash: "notApplicable"` | Деньги здесь неприменимы: запуск по подписке не оплачивается поштучно. |
| **«Общее окно квоты; расход запуска не выделен»** | `attribution: "shared"` | В то же время то же окно квоты расходовала другая работа, поэтому изменение нельзя приписать этому запуску. В итоги оно не входит. |

## `crewboard cost`

`crewboard cost` печатает по строке на воркера: запуски, минуты, деньги, токены, квоту и запуски, которые ещё ждут учёта. Например (цифры условные):

```text
dsh/deepseek-flash: 2 запуск(ов) · 14 мин · деньги $0.21 · токены 310.4k вход / 12.9k выход / 280.0k кэш
claude/opus: 3 запуск(ов) · 25 мин · оценка ≈$4.8 · токены 1.2k вход / 40.1k выход / 2100.0k кэш
codex/gpt-6-sol: 1 запуск(ов) · 9 мин · деньги: нет данных · квота +3%
```

Деньги идут двумя величинами, которые не складываются, как и на экране: `деньги` — что списано за запуски по API, `оценка ≈` — сколько запуски по подписке стоили бы по API-ценам. Если у воркера есть и то и другое, показаны обе. В `crewboard cost --json` итоги по воркерам (`totals`) содержат `cashUsd` и `apiEquivalentUsd` (каждое — только если запуски его сообщили), а у каждого запуска есть `billingMode` (`api`, `subscription`, `promotional`, `unknown`), `cashUsd` или `apiEquivalentUsd` с источником и запись `availability` для каждой метрики.

## Откуда берутся числа

- **Воркеры dsh.** Плагин учёта dsh пишет записи в `$DSH_HOME/dsh-bill/records.jsonl` (по умолчанию `~/.dsh`). Crewboard читает оттуда токены и доллары сессии запуска. dsh дописывает сессии из журналов при старте `dsh web`, поэтому свежий запуск может ждать учёта до следующего старта; CLI пишет «ждут учёта dsh-bill (перезапусти dsh web)». Если хотя бы у одной записи сессии нет цены, сумма остаётся неизвестной. **Проверьте в своём dsh**, что плагин учёта включён.
- **Claude Code.** Токены берутся из журналов Claude Code для рабочей копии запуска в `~/.claude/projects/` и оцениваются по опубликованным тарифам API. Недельная квота подписки читается из `~/.claude/usage/rate-limits.jsonl`, если на вашей машине что-то его пишет (например, скрипт строки состояния); иначе квота недоступна.
- **Codex.** Квота читается через `codex app-server` до и после запуска. Если прочитать её не удалось, проверка показывает «квота неизвестна», а запуск всё равно стартует.
- **Devin.** Запуски записываются с неизвестным способом оплаты, если Devin не сообщает стоимость.

Замер квоты не входит в итоги и тогда, когда окно сбросилось во время запуска.

## На экране

Экран **«Итоги»** сводит данные по плану: время плана, время воркеров, ожидание вас, потраченные деньги, потраченную квоту и токены. Если открыть запуск, виден его журнал шагов с расходом по времени и по шагам, и у каждого значения — одно из состояний выше.

Оценки по тарифам API годятся для сравнения воркеров и планов, но это не счёт.
