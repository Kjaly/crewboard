# Code of Conduct

This project adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in project spaces and when someone officially represents the project in public. Contributors, maintainers, and participants are expected to follow its standards, including respectful conduct and the prohibition of harassment.

## Reporting and enforcement

Report unacceptable behavior to the maintainer through [GitHub (@Kjaly)](https://github.com/Kjaly/crewboard). For abusive posts, use GitHub’s “Report content” feature. The maintainer will review reports, respect the privacy and safety of those involved, and apply the enforcement guidelines in Contributor Covenant 2.1. Do not put sensitive reports in public issues.
